# Nexa — Business OS

Nexa is a premium, mobile-friendly business command center designed for small businesses.

## Core modules
- Revenue dashboard
- Sales records
- Inventory tracking
- Customer management
- Expense tracking
- Invoices
- Public-facing storefront preview
- Local persistence with localStorage
- Installable PWA shell
